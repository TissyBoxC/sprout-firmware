# 初芽固件 0.16.0

本次更新把「实时查看」和「语音对讲」的设备端链路真正接上云端：此前设备能收到家长发起的请求，却无法把会话状态回报给平台，家长手机上会一直停在等待状态。

## 修复：实时查看的会话状态回报

设备现在会在每一个关键节点把会话状态同步到云端：

- 孩子同意后回报「已接听」，家长手机上立刻可见画面
- 摄像头不可用时回报「已拒绝」，家长看到的是一条明确的说明，而不是无限等待
- 孩子按键关闭、时长到期、家长主动结束时，都会回报结束原因

此前这些状态只发到了消息队列的确认主题，平台侧的会话记录收不到，会话会一直停留在等待中。

## 修复：语音对讲的会话状态回报

- 孩子接听后回报「已接听」，通话计时开始
- 孩子拒接或振铃超时回报「已拒绝」，家长可以区分「没人接」和「通话中断」
- 家长挂断、通话超时、连接失败统一回报「已挂断」

同时修正了一个会导致结束回报静默丢失的问题：设备主动结束通话时，通话标识在状态机结束通话的瞬间就被清空，导致后续回报用了空标识。现在标识在结束前先取出。

## 修复：对讲确认消息的主题

设备回报通话确认时用错了主题，平台收不到确认。现已改为与平台一致的 `commands/ack`。

## 修复：请求下发

实时查看和语音对讲的请求此前会被设备统一回成「不支持该指令」，家长发起后没有任何反应。现在两类请求都会被正确分派到对应模块；设备缺少对应能力时，回报稳定的拒收原因，而不是笼统的「不支持」。

## 新增：情绪记录上报

设备会把孩子当前的情绪状态按固定间隔上报到云端，家长端的情绪视图因此有了真实数据。

- 同一情绪在一分钟内不重复上报，避免刷屏
- 网络中断时先本地留存，恢复后按退避策略重试
- 上报内容只有情绪标签与时间，不含对话内容

## 新增：学习测评同步

设备可以复述家长在手机上给出的评分，并回填到测评记录。设备自身不打分、不猜分，超出范围的分数直接拒收而不是截断。

该能力默认关闭：目前还没有把测评会话通知到设备的通道，打开后设备也收不到要评哪一题。

## 配置调整

首款机型（初芽）默认开启摄像头、显示屏、触摸屏与实时查看能力。此前这些能力在默认配置里被关掉，导致实时查看请求一律被拒绝。

## 改进：可裁剪性

修正了一处条件编译错误：屏幕相关头文件被错误地放在对讲开关里，导致精简配置（关闭实时查看与对讲）无法编译。现在精简配置可以正常构建。

## 已知限制

- 实时查看只上报会话状态，尚未上传画面帧：家庭机型的摄像头驱动取帧接口还没有实现，画面通道待硬件型号确定后补齐
- 学习测评默认关闭，需要先补齐会话下发通道
- 生产环境镜像需要 Secure Boot 签名密钥，本地无法构建，由发布流水线完成

## 校验

发布包附带 `SHA256SUMS`，刷机前请先校验 `sprout-firmware-v0.16.0.bin`。
